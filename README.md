# Sable Mob Paths

Lets ground mobs walk between Sable sub-levels and the world: onto a moving structure, off it, and from one to the next. Villagers can live and work on one. NeoForge 1.21.1.

Sable paths a mob around the one sub-level it or its target is on. This mod handles the searches that cross from one to another.

- Needs [Sable](https://modrinth.com/mod/sable) 2.0.5 or newer.
- Turns itself off if [Sable Pathfinder](https://modrinth.com/mod/sable-pathfinder) is installed.
- No config, commands or new content.
- Villagers on a sub-level use the job sites, beds and bells on that same sub-level: they work, farm, sleep, breed and spawn golems there, and a Bad Omen starts a raid that follows it.
- Doesn't cover a villager claiming a site on a different sub-level, or amphibious mobs crossing onto one.
- Assumes sub-levels stay level: paths on a tilted one are approximate.

Check `latest.log` for `[SableMobPaths]` to see whether it is active.
